## ۱. واقعیت کلیدی داده روسیه

**روسیه از آوریل ۲۰۲۲ آمار گمرکی تفصیلی منتشر نمی‌کند** (طبقه‌بندی آمار FTS طبق مصوبه دولتی مارس ۲۰۲۲ — شماره دقیق مصوبه در R1 راستی‌آزمایی می‌شود). نتیجه:

- دوره 2021 تا Q1-2022: داده رسمی FTS در دسترس است.
- پس از آن: **داده آینه‌ای (mirror)** = جمع صادرات گزارش‌شده شرکا به روسیه، با تنظیم CIF→FOB (`κ ≈ 4–5%`، حساسیت 3–6%).

### چارچوب تحریم (context نمره‌دهی)
- فهرست‌های OFAC/EU/بریتانیا برای پرچم `sanctions_exposed` و وزن `sanctions_friction` — فقط به‌عنوان ریسک انطباق تجاری تحلیل می‌شود.
- زیرساخت پرداخت ایران–روسیه (Sepam/Shetab، SPFS، Mir، SLEI/RUICS-IPS — تعریف دقیق در R1) در تحلیل کانال پرداخت لحاظ می‌شود.

## ۳. ساختار داده مورد انتظار (schema پیش‌نویس)

| فیلد | نوع | مثال | توضیح |
|------|-----|------|-------|
| `year` | int | 2025 | میلادی — قرارداد ۴.۱ conventions |
| `hs6` | string | `"270900"` | HS6/ТН ВЭД (string!) |
| `hs2` | string | `"27"` | فصل |
| `flow` | string | `"mirror_import"` | mirror_import / official_export_ir / official_import_ru |
| `reporter_iso3` | string | `"CHN"` | کشور گزارش‌دهنده (برای mirror) |
| `partner_iso3` | string | `"RUS"` | روسیه = ثابت 643 |
| `value_usd_fob` | decimal | 1234567.8901 | پس از تنظیم CIF→FOB |
| `value_basis` | string | `"mirror_cif"` | مبدا ارزش برای ردیابی |
| `est_flag` | string | `"t"/"d"/"e"` | فلگ کیفیت منبع |

فایل‌های جانبی: `cbr-rates-annual.csv` (سال، نرخ)، `countries.csv` (iso3, m49, iso2, name_fa, name_en)، `sanctions-overlap.csv` (hs6، نوع محدودیت).

## ۴. ملاحظات فنی (میراث Issue-003 مرجع)

1. Rate-limit: حداقل ۲ ثانیه تأخیر بین درخواست‌ها؛ backoff نمایی در 429/503.
2. Encoding: همیشه UTF-8 راستی‌آزمایی شود.
3. snapshot: تاریخ دانلود در نام فایل (`__YYYYMMDD`) تا بازتولید تکرارپذیر باشد.
4. raw هرگز commit نمی‌شود — اسکریپت دانلود در `scripts/` منبع حقیقت بازتولید است.
5. هر منبع قبل از مصرف انبوه، با یک نمونه کوچک (۱ فصل/۱ فایل) اعتبارسنجی شود.
